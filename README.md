# Dometic 39424.602 — Raspberry Pi Control

Open-source Raspberry Pi control for the Dometic 39424.602 basement heat pump
used in older RVs. Replaces the obsolete Dometic 3312020.000 control board with
a Pi + relay HAT + SSR module.

## Features
- 2-minute compressor cooldown
- 24 F heat-pump lockout
- 4.5-min defrost cycle
- HTTP API (port 8080)
- MQTT with Home Assistant discovery
